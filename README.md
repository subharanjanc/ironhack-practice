# Ironhack AI Engineering - practice notebooks

My practice work from the **AI FT SEPT 26** bootcamp (instructor: Luis Junco).
The graded labs live in their own forked repositories; this repo holds the
in-class exercises and self-practice.

| Notebook | Topic |
|---|---|
| `functions_practice.ipynb`, `functions_practice_solved.ipynb` | functions, parameters, return values |
| `lambda_practice.ipynb` | lambda functions |
| `map_practice.ipynb` | `map()` - 10 small programs |
| `filter_practice.ipynb` | `filter()` |
| `reduce_practice.ipynb` | `reduce()` step by step |
| `map_filter_reduce_practice.ipynb` | all three side by side |
| `oop_practice.ipynb` | classes, instance attributes, `self` |
| `pandas_describe_practice.ipynb` | loading a CSV, `df.describe()` |
| `pandas_fundamentals_titanic.ipynb` | sorting, missing values (Titanic) |
| `groupby_practice.ipynb` | `groupby()`, `agg()` (Titanic) |
| `codewars_katas.ipynb` | Codewars katas |
| `practice_17sep.ipynb`, `sumnummer.ipynb` | scratch practice |
| `map_function.pdf` | short presentation on `map()` |

Datasets are in `data/` (`avocado_kaggle.csv`, `titanic.csv`).
